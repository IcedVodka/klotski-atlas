# 华容道 · 局面地图

复现 2swap《I Solved Klotski》的核心交互：棋盘与三维状态图联动、最短解播放、随机漫游、解集高亮、按距离或棋子相对位置染色、8 步局部邻域。

## 本地启动

需要 Python 3；没有外部前端依赖，也不需要构建。

```sh
npm start
# 或：python3 -m http.server 5173 --bind 127.0.0.1 --directory public
```

打开 http://127.0.0.1:5173 。浏览器需支持 WebGL。所有运行数据均在本地，不依赖 CDN。

## 操作

- 拖动棋子移动一格，或点选棋子后按方向键。
- 图中拖动旋转、滚轮缩放、Shift + 拖动平移；点击节点跳转到该局面。
- 图获得键盘焦点时，方向键旋转，`+` / `-` 缩放，`0` 恢复视角。
- 「单步」或「播放最短解」沿最短路径前进；支持暂停、调速、撤回、重置。
- 「局部邻域」突出显示当前节点 8 步内的状态；颜色菜单切换结构、到解的距离、目标块与横条的相对位置。

## 实现与边界

`public/engine.js` 实现棋盘规则、等价局面规范化、多源 BFS 和路径恢复；`graph.js` 使用原生 WebGL 批量绘制边与解集，Canvas 2D 绘制当前节点标记；`app.js` 处理交互和动画。

25,955 个节点、41,948 条无向边、964 个解局面。一步定义为棋子沿一个方向平移一格；作者开局距最近解 112 步，与常见标准开局相差 4 步。相同形状的棋子可互换身份。图中欧氏距离不等于实际移动步数。

当前版本复用作者预计算的三维布局，未在浏览器中重新运行力导向算法，也未复现视频里的全部关卡和剪辑。棋盘规则、路径计算、页面及渲染器为本项目实现。

## 验证

```sh
npm test
```

验证所有节点的全部邻边与独立棋盘移动规则一致、局面唯一、棋子无越界、整条最短路径合法并最终到达出口。
